# Glossary Map

Root map for multi-context domain docs. Each entry points to the glossary for one context.

| Context | Path | Scope |
| --- | --- | --- |
| server | `packages/server/GLOSSARY.md` | Framework runtime: routing, SSR, build, dev server, HMR |
| test-app | none | Private CI fixture; uses the server glossary's vocabulary |

System-wide decisions: `docs/adr/`.
Per-context decisions: `packages/<context>/docs/adr/` when they appear.
